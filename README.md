# home environment monitor

A Python and ESP8266-based home environment monitoring project for learning IoT, sensor integration, software architecture, data storage, networking, and analytics.
A learning project for building an environmental monitoring system using Python, sensors, an ESP8266, data storage, networking, and eventually analytics.

## Current stage

Simulated environmental measurements on the PC.

## Initial measurement data

- device ID
- timestamp
- temperature in °C
- relative humidity in %
